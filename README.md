# 国家电网 for Home Assistant

## 安装
如果您已经安装了 [HACS](https://hacs.xyz)，可点击按钮安装：

[![通过 HACS 下载安装](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=bluekiller&repository=sgcc_stat&category=integration)

如果您未使用 HACS，可下载并复制 `custom_components/sgcc_stat` 文件夹到
Home Assistant 数据目录下的 `custom_components` 文件夹内，即可完成安装。

## 配置
完成安装和重启后，可点击下方按钮添加集成：

[![添加集成](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start?domain=sgcc_stat)

或手工点击设置 - 设备与服务 -  添加集成 - 搜索`国家电网`添加。
